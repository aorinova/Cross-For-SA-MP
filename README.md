# Cross for SA-MP
## Этот репозиторий является исключительно архивом работы 2020 года
### Черный крест для SA-MP (GTA SA). Реализован в виде Lua скрипта.

- Установка: файл krest.lua закинуть в папку moonloader, krest.txd закинуть в папку moonloader/resource/txd (txd - папка, в неё саму кидать этот .txd файл).
- Команды (вводить в чат): /krest включить или выключить сам крест, /krest_pos установить позицию креста, /krest_size установить размер креста (от 1 (большого) до 3 (маленького))
- Требования: CLEO 4.3 (на 4.1 может быть будет работать), SAMPFUNCS 5.3.3+ (выше поддерживает), SA-MP 0.3.7 - R1 (ну или R2), MoonLoader 026 и выше (на v.027.0-preview3 работает).
- Скриншот: https://imgur.com/a/AN9PkMA
- Примечание: крест появляется через 5 секунд после спавна.
